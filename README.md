#1 спринт. Верстка. Семантика и лейаут. 
##Проектная работа: "Оно тебе надо"

В работе использовались:
* методология БЭМ для именования классов
* семантические теги HTML5
* CSS Grid для построения трёхколоночных сеток в хедере и футере, двухколоночной сетки в секции about
* Flexbox для выравнивания и распределения элементов в навигации, карточках лотов и подвале
* абсолютное и относительное позиционирование для наложения оверлея
* фоновые изображения и управление их размером и положением
* управление типографикой: межбуквенное расстояние, интервал между словами, подчёркивание с отступом, преобразование регистра
